# 周期向量与词嵌入实验完善性审查

日期：2026-10-25。范围：现有 v1.0 文档、模型与损失实现、原始 CSV、图件、原检查点的 CPU 数值复核。本文是本轮审查结果；补实验方案见 [completion_plan.md](completion_plan.md)。

> 范围更新：本文保留初始审查依据及当时建议；用户现已明确后续只验证 TQ。Queue/WTE 扩展建议不再是活动待办，当前后续以 [TQ 验证方案](completion_plan.md) 为准。已完成 P0 的新结果见 [阶段执行记录](phase1/execution_results.md)。

## 1. 结论先行

**现有实验支持“已训练文本分支使用了与日内索引相关的 TQ 条件信息，并依赖训练时的 WTE 字典”；尚未证明“加入 TQ/WTE 改善最终时序分支泛化”，也未证明“严格物理时角绑定、平滑日周期拓扑、语言语义不可替代”。**

这是证据层级不足，不等于周期向量无效。时间分支可能在训练中受益于联合监督和分支对齐，但需要重新训练的对照来确认。

| 待回答的问题 | 当前证据 | 审查判断 |
| --- | --- | --- |
| TQ 是否影响训练后的文本预测？ | 置零后 Text MSE +18.32%，错移 12h 后 +63.89% | 支持；属于固定模型的干预敏感性 |
| TQ 是否携带日内相位相关信息？ | 按行号模 144 查表，错配/随机索引造成退化 | 有支持，但需要对齐核验与更完整的相位响应 |
| TQ 是否提高最终 `outputs_time` 指标？ | 7 个推理条件的 Time MSE 全部相同 | 未验证；不能据此判定有效或无效 |
| 是否学习到强平滑、12h 反相的周期几何？ | 真实 TQ 几何与报告描述不符 | 不支持这一强结论；有微弱邻近有序性 |
| 预训练 WTE 是否优于随机字典？ | 训练后替换为全局矩匹配高斯字典造成退化 | 未验证公平的训练期比较 |
| 是否存在“光照/夜间抑制”专属语义原型？ | 两个日内分组的平均注意力不同 | 只能作为探索性关联，尚无功能干预验证 |

## 2. 已核验的模型关系

当前验证脚本采用 `tq_inject_target=q, tq_mode=add`：

```text
归一化时序 -> 线性投影 x_time --------------------> GPT2 时间分支 -> 共享预测头 -> outputs_time
                    \-> Q = x + TQ[输入末点索引]
WTE 字典 ----------------> K、V -> 交叉注意力/FFN -> GPT2 文本分支 -> 共享预测头 -> outputs_text
未来相位索引 -> cycle_queue * cycle_scale -------------------------------> 两分支输出
```

- `models/CALF.py:100-132` 中 `x_time` 在交叉注意力前保存。推理时仅修改 TQ/WTE 不会把文本分支输出重新送入时间分支；CSV 中 Time MSE 不变符合架构。
- `models/CALF.py:338-352` 的 `cycle_queue` 是另一条周期机制，与 TQ 必须分开评估；同一残差加到两个输出。
- `exp/exp_long_term_forecasting.py:551` 与 `run.py:159` 确认默认评测分支是 `time`。因此文本扰动幅度不能直接写成主任务收益。
- `utils/cmLoss.py:47-97` 使用双分支任务监督和特征/输出对齐，未对文本目标 `detach()`。这是联合优化；验证脚本声明的 `one_way_distill`、`task_time_ratio` 并没有使这里变成严格单向教师蒸馏。共享输入投影和预测头也提供训练耦合路径，不能把所有潜在收益单独归因于蒸馏。

## 3. 原有七组数值及其有效解释

来源：`figures/cycle_mechanism_validation/cycle_verification_results.csv`，7 行；本轮核对原文件，**未重跑全量推理**。

| 条件 | Text MSE | 相对 Clean | Time MSE |
| --- | ---: | ---: | ---: |
| Clean | 0.183072 | 0 | 0.164986 |
| TQ +72 步 | 0.300044 | +63.89% | 0.164986 |
| TQ 随机索引 | 0.345100 | +88.51% | 0.164986 |
| TQ +1 步 | 0.172125 | **−5.98%** | 0.164986 |
| TQ 置零 | 0.216616 | +18.32% | 0.164986 |
| WTE 置零 | 0.237119 | +29.52% | 0.164986 |
| WTE 高斯替换 | 0.324284 | +77.13% | 0.164986 |

重要区别：

1. **训练后消融和从头训练消融回答不同问题。** 模型适应了原条件输入，突然置零/换字典会形成分布偏移。退化说明依赖性，不能替代“有/无模块、相同预算重新训练”的增益比较。
2. **+1 步反而改善 5.98%，不能只解释为鲁棒。** 可能是相位偏差、模型误差或样本组成等原因。数据集返回输入末点索引 `s_end-1`，未来残差从 `s_end` 起；这一定义本身不构成错位 bug。应在验证集比较 ±1/±2 等偏移并核对预测目标约定，不能用测试集择优后再报告无偏收益。
3. `tq_random_permute` 实际执行 `torch.randint`，为各样本独立随机抽取索引，**不是一次固定的一一置换**。两种干预应分别命名并重复多个扰动种子。
4. 144 行查表不要求相邻行连续，错配退化并不能排除“时间类别记忆”。TQ 是可学习的相位条件参数；“利用相位”与“增加参数”并不互斥，LoRA 也不是这里的充分反事实。

## 4. 检查点直接复核：原报告有图文矛盾

使用验证脚本默认的 p100 / seed2025 检查点，CPU、`weights_only=True` 读取。TQ 为 `144×768`，WTE 为 `500×768`。

复算定义：`u_i=TQ_i/||TQ_i||`，`R(tau)=mean_i <u_i,u_((i+tau) mod 144)>`。

| 数值 | 复算结果 | 解释 |
| --- | ---: | --- |
| R(1)，10 分钟 | 0.009774780 | 原始向量的相邻相似度很弱 |
| R(6)，1 小时 | 0.003168241 | 未显示强平滑日周期形状 |
| R(72)，12 小时 | **+0.005781924** | 没有报告所称的负对跖低谷 |
| 非零滞后最小值 | −0.006887932 | 在 57、87 步，即 9.5h、14.5h；环形平均余弦具有对称性 |
| 非零滞后最大值 | 0.009774780 | 在 1、143 步 |
| R(144) | 1 | 模运算返回同一行，对任何非零查表矩阵均成立 |

原图 `cycle_autocorrelation_lag.png` 的最低点标注确实是 **9.5h、−0.007**。脚本只计算 `0..143` 步，在 24h 处画了一根标识线，没有观测到独立的“跨天恢复”。余弦热图的主对角线等于 1 同样是自相似恒等式，不能当作连续周期结构证据。

为避免把“小幅有序”误判成“完全随机”，补做了相邻相似度的行序置换检验：固定种子 `20251025`，4,999 次，置换零分布均值 `0.000777459`、标准差 `0.002968997`，单侧经验 p=`0.001`。**这是当前单检查点的探索性邻近有序信号，不证明物理时角绑定；没有初始化对照、跨种子确认，也不能证明 12h 反相。** 原始 768 维空间几何较弱也不排除投影后的任务空间存在有用结构。

### 字典几何为什么影响 WTE 对照

- WTE 行范数最大 `465.556563`、最小 `20.906801`、中位数 `27.639980`；前 50 行占总平方范数 `47.5742%`。
- 不同行的最大绝对余弦约 `1.67e-6`，与 PCA 得分列近似正交一致。
- 仅以整个矩阵的均值/标准差生成高斯替代物，会同时改变逐原型范数谱、正交关系和特征协方差。大幅退化既可能源自这些几何变化，也可能源自训练适应关系；不能单独解释为语言语义损失。
- `pca.py` 对 `wte.T` 执行 `PCA.fit_transform`，保存的是 PCA 得分字典；500 行并不是 500 个带词义标签的原始词 token。“光照专属原型”等命名需要额外证据。

### 两个低成本的架构核验

以实际 `Encoder_PCA`、严格加载其检查点参数、`eval()`、种子 `20251025`、合成输入形状 `2×137×96` 进行 CPU 检查。这些是结构检查，不是测试集预测指标：

| 操作 | 编码器文本输出最大绝对差 |
| --- | ---: |
| WTE 的 K、V 行同步置换 | `4.1425e-6`，仅浮点数累计误差量级 |
| TQ 表重排，同时对索引作逆置换 | `0` |

原因：这里 WTE 侧没有原型位置编码，同步重排 K/V 不改变注意力输出；TQ 一致重标号也不改变查表结果。因此 **WTE 行打乱不能作为破坏语义的负对照**，**训练和测试统一使用固定相位置换不能作为破坏周期信息的负对照**。后者仍完整保留时间类别信息。只打乱已训练表而不修正输入索引，检验的是错配敏感性。

## 5. 数据相位与统计完整性

- 原数据 `solar_AL.txt` 实测 `52,560×137`；按 7:1:2、96→96 计算测试窗口数确为 **10,417**。
- 周期索引来自 `np.arange(len(data)) % 144`，不是由时间戳/经度计算的太阳时角。训练段的全通道平均日内曲线在第 67 槽达到峰值，第 0 槽均值为 0，第 72 槽接近峰值，支持其日内活动解释；仍需记录起始时间、时区与采样间隔元数据，才能把槽位严格标为真实钟点。太阳时角还不能直接等同于普通时钟。
- 另核查了同目录 `solar_AL.csv`：它有连续 600 秒时间戳，从 `2006-01-01 00:10:00` 开始，但其 137 通道数值与当前 TXT 逐行比较的 RMSE 为 `0.812856`、最大绝对差为 `31.25`。测试行偏移 −2..+2 后仍不相同。因此不能把该 CSV 的时间戳直接当作当前 TXT 的已确认元数据，也不能把两文件当作相同数据无条件互换；这一发现不构成 TQ 存在一槽错位的证明。
- 10,417 个窗口以一步滑动，96 步预测之间高度重叠；137 个站点也不独立。不能用“样本很多”代替重复训练和相关性处理。
- 当前随机索引和随机 WTE 没有固定独立的干预种子、重复次数或置信区间。应分别处理训练种子方差与测试时间相关性。
- 注意力提取手工重建 `Q=x+TQ, K=WTE`，只适配当前 `q/add` 首层模式；它总做归一化、写死维度，并在两组各累计 80 个批次后停止，不能泛称全测试集/全配置的注意力验证。后续应从真实前向捕获注意力并保存分组样本数。
- 注意力分组同时改变了输入内容和相位，差异可能来自昼夜输入本身。应增加固定输入换相位、固定相位换输入的交叉对照，再做原型遮蔽/恢复，测量预测损失变化。注意力差异本身不是原型功能的证明；方法学依据参见 [Jain & Wallace, 2019](https://aclanthology.org/N19-1357/)。

## 8. 论文目前可采用的表述

> 在固定已训练模型上，移除或错配 TQ 条件会提高文本分支预测误差，表明该分支利用了与日内索引相关的条件信息。替换 WTE 字典也造成文本分支退化，说明其依赖训练时的原型表示。以上结果尚不能单独确立 TQ 对最终时间分支的泛化增益，或将字典收益归因于预训练语言语义；这些解释仍需训练期消融与几何匹配对照。

只有 [completion_plan.md](completion_plan.md) 中的主对照得到稳定正向结果后，才适合把结论升级为“加入周期向量改善预测”；物理解释与词嵌入来源优势需要各自独立的证据。
