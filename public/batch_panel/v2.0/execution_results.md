# 批量实验图形控制面板 (Desktop GUI Dashboard) 执行结果报告 (v2.0)

本文档记录 CALF 批量实验图形界面（Desktop GUI）、多线程异步实时控制台输出流、全超参调整、网格循环展开、断点续跑管理及大文件夹统一收敛特性的实施与验证结果。

---

## 一、交付物总览

依据用户需求与团队规范，本次 v2.0 迭代交付以下核心组件：

1. **图形界面核心模块**：
   - [scripts/batch_runner/gui_panel.py](file:///scripts/batch_runner/gui_panel.py)：基于 Python 内置 Tkinter/ttk 的现代桌面 GUI 控制台。
   - [batch_panel.py](file:///batch_panel.py)：入口重构，默认直接启动桌面 GUI；无显示环境或指定 `--cli` 时平滑回退至 TUI 菜单；指定 `--run` 时无头静默运行。
   - [run_one_click.ps1](file:///run_one_click.ps1)：主控制台选项 `[6]` 升级为直通桌面 GUI 启动。
2. **多线程异步流式输出引擎**：
   - 采用多线程守护进程模型（`threading.Thread` + `queue.Queue`），GUI 主事件循环与子进程运行完全解耦，彻底避免训练时界面“无响应（Not Responding）”卡死；
   - 实时流式捕获训练日志输出，并对 `Epoch: `、`Validation loss decreased`、`Best model stored`、`mse: ..., mae: ...` 等关键指标实时着色高亮；
   - 支持自动滚动追踪最新输出行，以及一键清空和复制控制台日志。
3. **断点续跑状态可视化与操作**：
   - 界面右侧任务清单以彩色状态标签实时呈现：`COMPLETED`（绿）、`RUNNING`（蓝）、`PENDING`（灰）、`FAILED`（红）；
   - 顶置高精度进度条（`ttk.Progressbar`）动态展示整体完成比例；
   - 支持实时中断（`⏹ 停止运行`），安全退出子进程并持久化断点状态；再次点击 `▶ 启动 / 断点续跑` 时，自动跳过已完成项，从最后一个中断点继续。
4. **全超参配置与循环扫描**：
   - **循环参数页签**：以直观表格展示当前循环超参（如 `random_seed: [2025, 2026, 2027]`、`cycle: [24, 48]`、`task_w: [0.5, 1.0, 2.0]`），支持随时添加、编辑与删除；支持一键切换“全组合网格（Grid）”与“并列对齐（Paired）”模式；
   - **固定基础参数页签**：分组折叠卡片，可直接查看并修改 30+ 关键超参（数据路径、序列长、模型维度、GPT层数、TQ注入方式、学习率、损失权重等）。
5. **权重保存大文件夹统一管理**：
   - 原生支持 Windows 文件夹选择器（`[浏览文件夹...]`）；
   - 提供快捷预设：`新建时间戳隔离目录`（自动生成 `batch_YYYYMMDD_HHMMSS`）、`Solar-AL 基准复现目录`、`少样本微调扫描目录`；
   - 选定后，该批次所有模型的 checkpoint、独立日志与 `batch_state.json` 全量收敛至该大文件夹。

## 四、启动方式

### 1. 直接双击或命令行启动桌面 GUI（默认）
```powershell
& "D:\software\conda\envs\calf\python.exe" batch_panel.py
```
*或在主启动器 [`run_one_click.ps1`](file:///run_one_click.ps1) 菜单输入 `6` 启动。*

### 2. 其它模式参数
```powershell
# 强制启动终端字符菜单 (在 SSH 或纯命令行环境下)
& "D:\software\conda\envs\calf\python.exe" batch_panel.py --cli

# 无头后台运行
& "D:\software\conda\envs\calf\python.exe" batch_panel.py --config configs/batch_templates/solar_al_seeds.json --checkpoints ./checkpoints/my_run/ --run
```
