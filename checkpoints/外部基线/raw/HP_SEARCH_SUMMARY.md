# Solar-96 超参搜索总结报告（TQNet × CycleNet）

> 存放于 **CycleNet** 仓库 · TQNet / CycleNet 两仓库同名副本，内容一致

本报告覆盖两个仓库、2 个模型、3 个 model_type、2 个数据集、共 6 个搜索阶段。**唯一可调参数为 `learning_rate` 与 `batch_size`**，每组固定跑 3 个随机种子（2025 / 2026 / 2027）取平均 MSE 作为判据。

固定配置：`seq_len=96, pred_len=96, cycle=144, use_revin=0, train_epochs=30, patience=5, features=M, percent=100, bestmodel, data=Solar`；统一环境 `conda tqnet` (torch 2.4.1+cu121)，GPU RTX 4070 Laptop 8GB。

## 二、关键结论

1. **总成本**：6 个阶段合计 149 组 / 454 次训练，最大单组提升 **−30.84%**（CycleNet-linear / Solar-IL）。
2. **最优 lr 不可跨数据集迁移**。AL 数据集上最优 lr 落在 3e-3 ~ 5e-3 量级（TQNet 0.005、CycleNet-linear 0.0045、CycleNet-mlp 0.0028~0.0054），IL 数据集上低一个数量级（TQNet 6e-4、CycleNet-linear 1.4e-3）。换数据集必须重扫，且优先从低 lr 侧试。
3. **换 model_type 也要重扫 batch_size**。同一 AL 数据集上，CycleNet-linear 最优 bs=64，CycleNet-mlp 最优 bs=256（次优 128）；bs=96 在 MLP 上全程最差。
4. **`bs=64` 通常只是次优点，不是最优**。沿大 batch 方向存在两条独立的上升通道：bs=128 顶点 lr≈0.0028~0.0030，bs=256 顶点 lr≈0.0048~0.0054，两者最优「有效 lr」(lr/bs) 相差约一倍，**不满足简单的 lr/bs 缩放律**。
5. **早停坍塌（early-stopping collapse）需剔除**。TQNet 在 AL 上部分 lr≥0.004 取值会被seed2026 在 80~190s 内提前早停（MSE≈0.212），属异常点，会显著拉高组均值；IL 数据集上未复现该现象。判断最优时应同时参考组内种子极差。
6. **低 lr 侧因欠拟合回升**。Solar-IL 上 TQNet lr=1e-4 → 0.2024、CycleNet-linear lr=5e-4 → 0.2506，确认下方存在真实谷底而非单调区间。

## 五、搜索方法与复现

### 驱动脚本

```bash
MODEL=CycleNet MODEL_TYPE=mlp SUBDIR=tuning_AL_mlp \
  DATA_PATH=solar_AL.txt ENC_IN=137 MODEL_ID=Solar_96_96 \
  bash tuning/run_sweep.sh
```

- 队列文件 `queue.txt`（每行 `lr<tab>bs`）跑空后驱动进入 20s 轮询待命，可随时追加任务；放入 `stop` 文件即优雅退出。
- `done.txt` 以 `lr<tab>bs<tab>seed` 去重（固定字符串 + 真制表符匹配），同一 lr/bs 的三个种子集齐才写入 `summary.txt`。
- **坑 1**：去重键不含 model_type，切换 model_type 必须换 `SUBDIR`，否则任务会被误判为已完成。
- **坑 2**：bash 双引号内写 `\t` 是字面量而非制表符，须用 `printf` 生成真制表符。
- **坑 3**：Windows 前台长 `sleep` 超时被 SIGTERM 会连带杀掉后台训练进程组，长期驱动必须用受管后台任务启动。
- **坑 4**：kill 驱动后仍有孤儿训练 python 占显存，需 `taskkill //F //PID` 清理（实测 GPU 从 7586 MiB 回落到 1478 MiB）。

### 数据格式约定

- `Dataset_Solar` 以 `pd.read_csv(..., header=None)` 直读无表头 txt，不能喂带 `date` 表头的 csv，否则字符串列进 StandardScaler 会报错。
- csv → txt 规则：`np.savetxt(path, df.iloc[:, 1:].to_numpy(float), delimiter=",", fmt="%.18e")`。
- Solar-AL = 137 站（solar_AL.txt，137 列），Solar-IL = 106 站（solar_IL.txt，106 列），均为 52560 行 @10 分钟采样，故 `cycle=144` 通用。
