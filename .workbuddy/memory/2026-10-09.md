## percent 扫描全量重跑（修复 scratch 训练后，11:43~14:21，5×3=15 次）
产出：`CALF_Solar_percent扫描汇总.xlsx`（sheet1 竖排 MSE/MAE；sheet2 新旧对比）

新批 ave（percent 10/20/30/40/50）：
- MSE: 0.204736 / 0.188609 / 0.184740 / 0.183657 / **0.179190**
- MAE: 0.216503 / 0.204875 / **0.204731** / 0.208754 / 0.208725

关键结论：
1. **新批全面差于旧批**（MSE +1.8%~+7.2%，percent 越大差距越大：40 处 +7.24%）。
   成因推断：旧批 percent<100 时会加载已有 checkpoint（迁移/泄漏），分支
   `percent_scratch_train` 的 commit "support training new model from scratch when percent<100
   without requiring checkpoint" 修复了该行为 → 新批从零训练，指标变差但**更真实可信**。
   ⚠️ 这是推断，未经直接验证，报告论文时以新批为准。
2. 新批下 **percent 单调有效**（MSE 0.2047→0.1792，全程下降），旧批在 40 出现的"拐点"是假象。
3. **MAE 在 percent=30 处最优（0.204731）**，40/50 反而回升到 0.2088 → MAE 与 MSE 最优不同步。
4. percent=10 的 seed2026 是明显异常值（MSE 0.2194 vs 另两个 0.196/0.199），建议补跑。
